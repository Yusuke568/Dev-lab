# SES勤怠管理・勤務報告書システム要件定義書
## 01. システム概要書

### 1.1 システム名称
**SES勤怠管理・勤務報告書システム（SES Attendance & Work Reporting System）**

### 1.2 システム概要
本システムは、SES（システムエンジニアリングサービス）業界特有の勤務形態・契約形態に特化した勤怠管理および週報報告Webアプリケーションです。  
クライアント常駐型業務における「契約精算幅（下限・上限時間）に基づく過不足精算」「36協定および年5日有給義務の労基コンプライアンス管理」「中抜け休憩や客先間接時間を含んだ日次勤怠管理」「週次でのメンタル・稼働モニタリング（週報）」を一元的に管理します。

### 1.3 SES業界における現状の課題
1. **複雑な契約精算計算の属人化**: 案件ごとに異なる基準時間・精算幅（例: 140h〜180h）や超過・控除単価の計算が手作業で行われ、請求ミスや確認コストが生じる。
2. **労基コンプライアンス違反のリスク**: 常駐先での突発的な残業や有給未消化に対し、36協定上限（45h/月、特別条項80h/月）や年5日有給取得義務の予兆検知が遅れる。
3. **客先常駐エンジニアの状況把握難**: 勤務地が分散しているため、稼働過多やメンタルヘルス不調（健康度低下）の早期察知が困難。
4. **月次勤怠入力の負担**: 毎日の出退勤や客先休憩時間の設定を手動で行うと入力漏れや月末集中が発生する。

### 1.4 システムの目的
1. **SES契約精算の自動化**: 月間総稼働時間から精算ステータス（精算幅内・控除・超過）および精算金額を即時自動算出する。
2. **労務コンプライアンスの先手管理**: 36協定残業レベル（NORMAL / WARNING / DANGER / VIOLATION）および年5日有給取得義務の遵守状況をリアルタイムで警告する。
3. **エンジニアフォローの迅速化**: 週報による「作業進捗」「本人所感」「負荷スコア」「健康スコア」を収集し、早期エスカレーションとコメント支援を実現する。
4. **勤怠入力負荷の削減**: 月間テンプレート一括適用、中抜け休憩、非同期保存（Fetch API）によるストレスフリーな勤怠入力環境を提供する。

### 1.5 対象範囲
#### システム化対象業務
- **社員情報・権限管理**: 社員登録・更新・削除、ロール別アクセス制御（USER / MANAGER / ADMIN）
- **SES日次勤怠入力**: 出退勤時刻、休憩時間、中抜け休憩、直接/間接作業時間、適用区分、備考
- **月間テンプレート適用**: 標準就業時間（例: 09:00〜18:00、休憩1h）や土日祝の自動判定・一括反映
- **SES契約・精算管理**: 案件契約マスタ、アサイン情報、精算幅（下限〜上限）の判定と精算額算出
- **コンプライアンス監査**: 36協定残業時間アラート、有給休暇残日数・年5日取得義務管理
- **週報・レビュー管理**: 週次報告書作成、負荷・体調スコア、上司レビューコメント

#### 対象ユーザー
- **一般エンジニア（USER）**: 日次勤怠入力、月間テンプレート適用、週報提出、有給残日数確認
- **プロジェクトマネージャー / 営業（MANAGER）**: 配下エンジニアの勤怠・週報レビュー、精算サマリ確認
- **人事・労務管理者（ADMIN）**: 全社社員管理、有給自動付与ルール設定・実行、コンプライアンス監査

### 1.6 システム構成
#### 技術スタック
- **フロントエンド**: HTML5, Tailwind CSS, Vanilla JavaScript (Modern Fetch API)
- **バックエンド**: Java 11 (Servlet 4.0, JSP 2.3, JSTL 1.2)
- **アーキテクチャ**: ヘキサゴナル／クリーンアーキテクチャ + FrontController + Commandパターン
- **データベース**: MySQL 8.0 (InnoDB, utf8mb4)
- **アプリケーションサーバー**: Apache Tomcat 9.0

#### 外部連携・データ基盤
- 社員マスタ (`staff_table`)、役職マスタ (`class_master`)、ログインテーブル (`login_table`)
- 勤怠テーブル (`work_month_table`, `daily_attendances`, `work_time_segments`)
- SES契約テーブル (`project_contracts`, `assignments`, `monthly_summaries`)
- 週報テーブル (`weekly_reports`, `weekly_report_comments`)
- 有給付与テーブル (`leave_grant_rules`)

### 1.7 期待効果
#### 定量的効果
- 月末勤怠集計・精算計算時間: 80%削減（自動精算判定による手作業排除）
- 36協定・労基法違反件数: 0件（リアルタイム段階アラートによる未然防止）
- 週報提出完了率: 95%以上（テンプレートと簡易スコア入力による負担軽減）

#### 定性的効果
- エンジニアの就業環境・健康状態の可視化による早期ケア
- 顧客企業との請求・精算トラブルの完全防止
- クリーンアーキテクチャ採用によるシステムの高い保守性・拡張性
