# SES勤怠管理・勤務報告書システム要件定義書
## 04. 画面設計書

### 4.1 UI/UXデザインコンセプト
- **モダン＆クリーン**: Tailwind CSSを採用し、視認性の高いカード型サマリーと洗練されたテーブルUIを提供。
- **入力ストレスの最小化**: 日次勤怠入力はページ全体のリロードを行わず、Fetch APIを用いたリアルタイム非同期保存。
- **即時フィードバック**: 36協定の残業時間超過アラートやSES精算ステータスをバッジやカラーインジケータで直感的に可視化。

## 4.3 主要画面レイアウト設計

### 4.3.1 SCR-02: SES勤怠管理画面 (`ses_attendance.jsp`)

月次の勤怠実績を一元管理するメイン画面です。

```text
┌────────────────────────────────────────────────────────────────────────┐
│  Dev-lab SES勤怠管理              [2026年10月 ▼]      田中太郎 (ログアウト)│
├────────────────────────────────────────────────────────────────────────┤
│ ■ 月次稼働サマリー & 精算ステータス                                     │
│ ┌──────────────┬──────────────┬──────────────┬──────────────┐         │
│ │ 総稼働時間   │ 契約精算幅   │ 精算ステータス│ 36協定状況   │         │
│ │   168.0 h    │ 140.0-180.0h │ [幅内 基準内]│ [NORMAL 良好]│         │
│ └──────────────┴──────────────┴──────────────┴──────────────┘         │
│                                                                        │
│ [⚡ 月間テンプレート適用 (09:00-18:00)]   [週報を作成・確認]           │
├────────────────────────────────────────────────────────────────────────┤
│ ■ 月間勤怠カレンダー                                                   │
│ ┌────┬──┬─────┬─────┬─────┬────┬────┬───────┬──────┬────────┐       │
│ │日付│曜│始業 │終業 │休憩 │中抜│実働│区分   │作業  │備考    │[保存]  │
│ ├────┼──┼─────┼─────┼─────┼────┼────┼───────┼──────┼────────┤       │
│ │10/1│木│09:00│18:00│60分 │0分 │8.0h│通常勤務│直:8h │設計    │[済]    │
│ │10/2│金│09:00│19:30│60分 │0分 │9.5h│通常勤務│直:9.5│実装    │[済]    │
│ │10/3│土│--:--│--:--│0分  │0分 │0.0h│所定休日│--    │        │[済]    │
│ │10/4│日│--:--│--:--│0分  │0分 │0.0h│法定休日│--    │        │[済]    │
│ │10/5│月│09:00│18:00│60分 │60分│7.0h│通常勤務│直:7h │通院中抜│[保存]  │
│ └────┴──┴─────┴─────┴─────┴────┴────┴───────┴──────┴────────┘       │
└────────────────────────────────────────────────────────────────────────┘
```

#### 主要コンポーネントと操作仕様
1. **サマリーカード**:
   - 総稼働時間、直接作業時間、間接作業時間をリアルタイム集計。
   - SES契約情報（精算幅: 140h〜180h等）と照合し、現在の精算ステータス（`WITHIN_RANGE`, `DEDUCTION`, `OVERTIME`）を表示。
   - 36協定レベル（`NORMAL`, `WARNING`, `DANGER`, `VIOLATION`）をバッジカラーで警告。
2. **テンプレート適用ボタン**:
   - クリック時、当月の全平日に標準勤務時間を一括適用（確認ダイアログ付き）。
3. **カレンダー行の非同期更新**:
   - 各行の入力変更時、または「保存」ボタン押下時に `/api/sesAttendance.do` へ非同期JSON通信。ページリロードなしで集計値が再計算される。
