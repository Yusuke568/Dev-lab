08. プロジェクト参画オンボーディングガイド
〜初日で環境構築・起動・テスト・作法を完全マスター〜

本プロジェクトへようこそ！このガイドは、新規参画者が初日でローカル環境を立ち上げ、 単体テストを実行し、開発の流れを理解して最初のタスクに着手できるようにするための実践手順書です。

Prerequisites

1. 技術スタックと事前インストール要件

☕ 開発言語・ランタイム
・Java: Java 17 (OpenJDK / Eclipse Temurin)
・ビルドツール: Apache Maven 3.8+
・サーブレットコンテナ: Apache Tomcat 9.0 (Port 8081)
🗄️ データベース・フロントエンド
・DB: MySQL 8.0 (Port 3306)
・接続情報: DB kintai / ユーザー kintai / PW kintai
・フロント: JSP, JavaScript (Vanilla), Tailwind CSS (静的20KB)
Step by Step

2. ローカル環境セットアップ（3ステップ）

Step 1

データベースの作成とサンプルデータ投入

MySQLにログインし、テーブル作成と初期データを投入します。

# 1. データベース作成 & テーブル定義
mysql -u kintai -pkintai kintai < 20.db/createtb/ses_tables.sql

# 2. 初期マスタ・サンプルデータ投入（社員・契約・摘要・過去週報）
mysql -u kintai -pkintai kintai < 20.db/sampleinsert/ses_sample_data.sql
Step 2

Maven ビルドと超高速単体テストの実行

DBやTomcatを起動しなくても、ビジネスルールの全テスト（20件）が一瞬で走ります。

cd 10.project/webapp2
mvn clean test

# 実行結果例:
# [INFO] Tests run: 20, Failures: 0, Errors: 0, Skipped: 0
# [INFO] Total time: 0.840 s -- BUILD SUCCESS
Step 3

Tomcat 起動とブラウザアクセス

Eclipse / WTP またはスタンドアロンTomcatで webapp2 を起動します。

# ログイン画面URL
http://localhost:8081/webapp2/login.do

# メインSES勤怠・週報ダッシュボードURL（ログイン後自動リダイレクト）
http://localhost:8081/webapp2/sesAttendance.do

Rules & Don'ts

4. 開発の鉄則（やってはいけないこと集）

❌ 1. ドメイン層（domain/）に外部APIを持ち込まない

javax.servlet.* や java.sql.* をドメインクラスでインポートしてはいけません。ドメイン層は純粋なJava標準クラスのみで完結させてください。

❌ 2. 廃止された com.example パッケージを復活させない

過去のリファクタリングにより com.example は完全撤廃されました。新規クラスは必ず domain/, usecase/, infrastructure/, controller/ 直下に配置してください。

❌ 3. テスト（mvn test）を壊したままコミットしない

本プロジェクトには強力な単体テストがあります。コードを変更したら必ず mvn test を叩き、20件全パスを確認してください。
