## 1. 技術スタックと事前インストール要件

- **Java**: Java 17 (Eclipse Temurin / OpenJDK 17)
- **ビルドツール**: Apache Maven 3.8+
- **データベース**: MySQL 8.0 (Port 3306)
  - 接続情報: DB `kintai` / ユーザー `kintai` / パスワード `kintai`
- **アプリケーションサーバー**: Apache Tomcat 9.0 (Port 8081)
- **フロントエンド**: JSP, JavaScript (Vanilla), Tailwind CSS (静的ファイル 20KB)

## 2. ローカル環境セットアップ（3ステップ）

### Step 1: データベース構築と初期データ投入
```bash
# 1. テーブル定義の作成
mysql -u kintai -pkintai kintai < 20.db/createtb/ses_tables.sql

# 2. 初期マスタ・サンプルデータの投入
mysql -u kintai -pkintai kintai < 20.db/sampleinsert/ses_sample_data.sql
```

### Step 2: Maven ビルドと単体テスト実行
```bash
cd 10.project/webapp2
mvn clean test

# 実行結果例:
# [INFO] Tests run: 20, Failures: 0, Errors: 0, Skipped: 0
# [INFO] Total time: 0.840 s -- BUILD SUCCESS
```

### Step 3: Tomcat 起動とブラウザアクセス
Tomcat 9 を起動し、以下のURLにアクセスします。
- **ログイン画面**: `http://localhost:8081/webapp2/login.do`
- **勤怠・週報ダッシュボード**: `http://localhost:8081/webapp2/sesAttendance.do`

## 4. 開発の鉄則（やってはいけないこと集）

1. **❌ ドメイン層（`domain/`）に外部APIを持ち込まない**
   - `javax.servlet.*` や `java.sql.*` をドメインクラスでインポートしてはいけません。
2. **❌ 廃止された `com.example` パッケージを復活させない**
   - パッケージは `src/main/java/` 直下の4層（`domain/`, `usecase/`, `infrastructure/`, `controller/`）で統一されています。
3. **❌ テスト（`mvn test`）を壊したままコミットしない**
   - 変更後は必ず `mvn test` を実行し、全20テストが合格することを確認してください。
