11. SES勤怠・週報ドメイン業務ルール解説書
〜精算幅・36協定・中抜けスケジュール・週報決裁〜

SES（準委任契約）特有の複雑なビジネスルールが、本システムのコード上でどのように定義され、 どのクラスで整合性が担保されているかを体系的に解説します。

Rule 01

1. 客先精算幅ルール（控除・割増計算）

準委任契約では、月間の客先直接稼働時間に対して「下限時間」と「上限時間」（例: 140h〜180h）が定められます。

📉 下限割れ（DEDUCTION）
・実働 < 140h
・不足時間分の請求額を控除
✅ 精算幅内（WITHIN_RANGE）
・140h ≦ 実働 ≦ 180h
・基本月額固定で精算なし
📈 上限超過（OVERTIME）
・実働 > 180h
・超過時間分の割増請求が発生
// 実装クラス: domain.contract.SettlementService
public SettlementResult calculate(ProjectContract contract, int prescribedDays, int actualWorkDays,
                                  int totalDirectMinutes, double allocationRatio) {
    double actualHours = totalDirectMinutes / 60.0;
    if (actualHours < contract.getBillingLowerLimitHours()) {
        // 下限割れ控除計算
        return new SettlementResult(SettlementStatus.DEDUCTION, deductionAmount, ...);
    } else if (actualHours > contract.getBillingUpperLimitHours()) {
        // 上限超過割増計算
        return new SettlementResult(SettlementStatus.OVERTIME, overtimeAmount, ...);
    }
    return new SettlementResult(SettlementStatus.WITHIN_RANGE, BigDecimal.ZERO, ...);
}
Rule 02

2. 労務コンプライアンス（36協定・有給年5日取得義務）

🛡️ 36協定・法定外残業アラート

1日8時間を超える法定外残業時間を日次でリアルタイム合算。
・35時間以上: 「注意アラート（警告）」
・45時間超過: 「法令違反アラート（即時指導）」
実装: domain.compliance.Article36ComplianceService

🏖️ 有給休暇 年5日取得義務の進捗監視

年休付与後1年以内に5日の取得が法令で義務付けられています。
半年経過時点で取得日数が2日未満の場合、システムが未達ペースを警告。
実装: domain.compliance.PaidLeaveComplianceService

Rule 03

3. 直接/間接労働時間と中抜け休憩の整合性ルール

SESでは「客先直接勤務（09:00〜18:00）」と「自社定例MTG（19:00〜20:00）」のように、 勤務の間にすきま時間（移動・夕食）が発生します。

📐 時間整合の基本等式
拘束時間(始業〜終業) − 休憩時間(昼休 ＋ 中抜け) ＝ 実労働合計 ＝ 直接労働 ＋ 間接労働

UI側で直接終了〜間接開始のすきま時間を「中抜け休憩」として自動合算することで、 DailyAttendance.validateSegmentsIntegrity() の検証を完璧にパスさせます。

Rule 04

4. 週報多層承認ワークフローと日次未入力ガード

［下書き: DRAFT］
       │ （日次勤怠に未入力がないことを検証して提出）
       ▼
［提出済: SUBMITTED］ ──（差戻し: REMANDED）──▶ 修正・再提出
       │
       │ （課長が「課長所見」を記入）
       ▼
［一次確認済: REVIEWED_PRIMARY］
       │
       │ （所属長が「所属長所見」を記入・最終決裁）
       ▼
［最終承認完了: APPROVED_FINAL］
・未入力ガード: 当該週に未入力の日次勤怠がある場合、週報提出はドメイン例外でブロックされます。
・休暇スキップ: 長期休暇（GW・夏期）の週は、理由を記録して SKIPPED ステータスに遷移可能。
・管理者共有メモ: 社員には見えない上司・営業間の引き継ぎメモを別枠で記録。
