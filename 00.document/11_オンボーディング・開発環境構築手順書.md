## 2. 3ステップ環境構築手順

### Step 1: データベースの作成と初期データ投入
ターミナルを開き、MySQLに管理者権限で接続して以下のコマンドを実行します。

```bash
# 1. データベース 'kintai' の作成
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS kintai DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"

# 2. 基本テーブルおよびビューの作成
mysql -u root -p kintai < 20.db/createtb/all_createtables.sql
mysql -u root -p kintai < 20.db/createtb/all_createviews.sql

# 3. SES拡張テーブルの作成
mysql -u root -p kintai < 20.db/createtb/ses_tables.sql

# 4. サンプルデータの投入 (全SQLを一括投入)
for f in 20.db/sampleinsert/*.sql; do
    echo "Importing $f..."
    mysql -u root -p kintai < "$f"
done
```

### Step 2: Mavenビルドと自動テスト実行
アプリケーションディレクトリへ移動し、ビルドとJUnit単体テストを実行します。

```bash
cd 10.project/webapp2
mvn clean test
```
- **成功の目安**: `BUILD SUCCESS` が表示され、20件のテストが0エラー・0失敗でパスすること（所要時間: 約2秒）。

### Step 3: WARパッケージングとTomcatデプロイ
```bash
mvn package
```
- 生成された `target/webapp2.war` を Tomcat の `webapps/` に配置するか、VSCode / Eclipse の Tomcat 拡張機能から `10.project/webapp2` をプロジェクトとして追加してサーバー起動します。

## 4. 動作確認シナリオ

1. **ログインとロール制御の確認**:
   - ブラウザで `http://localhost:8080/webapp2/login.do` を開く。
   - `1002` / `password` でログイン → 自動的に `/sesAttendance.do` に遷移することを確認。
   - ログアウト後、`1003` / `password` でログイン → 自動的に `/shainList.do`（社員一覧）に遷移することを確認。
2. **月間テンプレート適用とリアルタイム保存**:
   - `1002` で勤怠画面を開き、「月間テンプレート適用」ボタンを押下。
   - 平日すべてに 09:00〜18:00（実働8.0h）がセットされ、総稼働時間が即時再計算されることを確認。

   - `1003` (ADMIN) で `/paidLeaveAdmin.do` にアクセス。
   - 「全社員に有給を一括付与する」を押下。全社員の有給日数が増加することを確認。

## 5. 開発時の「NG集」（やってはいけない実装アンチパターン）

1. ❌ **ドメインモデルに `java.sql.*` や `javax.servlet.*` をインポートすること**:
   - ドメイン層は純粋なPOJOでなければなりません。DB接続やHTTPリクエストを持ち込むと、単体テストが書けなくなります。
2. ❌ **JSP内に `<% ... %>`（スクリプトレット）を書くこと**:
   - 画面描画は必ず JSTL（`<c:forEach>`, `<c:if>` 等）および EL式（`${...}`）を使用してください。
3. ❌ **DAO内で `con.commit()` や `con.rollback()` を呼ぶこと**:
   - トランザクション境界は Service / UseCase 層の `TransactionManager` が一括管理します。DAOは渡された `Connection` でSQLを実行するだけに専念してください。
4. ❌ **SQL文をJavaコード内で直接文字列連結（`"WHERE id = " + id`）すること**:
   - 重大なSQLインジェクション脆弱性となります。必ずプレースホルダー（`?`）と `PreparedStatement` を使用してください。
5. ❌ **業務計算ロジックを Action（Controller）内に直接書くこと**:
   - Fat Controllerの再発を防ぐため、計算式は必ずドメインエンティティまたはドメインサービスに記述してください。
