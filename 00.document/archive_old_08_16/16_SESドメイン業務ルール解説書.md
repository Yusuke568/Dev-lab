## 1. 客先精算幅ルール（控除・割増計算）

SES（準委任契約）では、月間の客先直接労働時間に対して精算幅（下限〜上限時間、例: 140h〜180h）が設定されます。

| 判定ステータス | 条件 | 請求・精算の扱い |
|:---|:---|:---|
| **DEDUCTION** (下限割れ) | 実働客先時間 < 下限時間 (140h) | 不足時間分を基本月額から控除 |
| **WITHIN_RANGE** (精算幅内) | 140h ≦ 実働客先時間 ≦ 180h | 基本月額の満額（精算なし） |
| **OVERTIME** (上限超過) | 実働客先時間 > 上限時間 (180h) | 超過時間分の割増請求が発生 |

- **実装クラス**: `domain.contract.SettlementService`

## 2. 労務コンプライアンス（36協定・有給年5日取得義務）

### 36協定（法定外残業アラート）
- 1日8時間を超える法定外残業時間を日次でリアルタイム合算。
- **35時間以上**: `OvertimeLevel.WARNING`（注意アラート表示）
- **45時間超過**: `OvertimeLevel.VIOLATION`（法令違反警告）
- **実装クラス**: `domain.compliance.Article36ComplianceService`

### 有給休暇 年5日取得義務
- 年休付与後1年以内に5日以上の取得が義務付けられています。
- 付与から半年経過時点で取得日数が2日未満の場合、警告メッセージを表示。
- **実装クラス**: `domain.compliance.PaidLeaveComplianceService`

## 3. 直接/間接労働時間と中抜け休憩の整合性ルール

SES特有の「客先勤務（09:00〜18:00）」と「自社定例会（19:00〜20:00）」の中抜けスケジュールに対応。

```
拘束時間(始業〜終業) − 休憩時間(昼休 ＋ 中抜け) ＝ 実労働合計 ＝ 直接労働 ＋ 間接労働
```

- **中抜け自動合算**: 客先終業から社内開始までのすきま時間（例: 60分）を「中抜け休憩」として自動合算。
- **自己防衛**: 実労働合計と内訳合計（直接＋間接）が一致しない場合、`DailyAttendance` が例外を投げて不整合を防止。
- **実装クラス**: `domain.attendance.DailyAttendance`

## 4. 週報多層承認ワークフローと未入力ガード

### 承認ステータス遷移
```
［下書き: DRAFT］
       │ （当該週の日次勤怠がすべて入力されていることを検証して提出）
       ▼
［提出済: SUBMITTED］ ──（差戻し: REMANDED）──▶ 修正・再提出
       │
       │ （課長が「課長所見」を記入）
       ▼
［一次確認済: REVIEWED_PRIMARY］
       │
       │ （所属長/部長が「所属長所見」を記入・最終決裁）
       ▼
［最終承認完了: APPROVED_FINAL］
```

- **日次未入力ガード**: 週内に未入力の日次勤怠がある場合、週報提出はドメイン例外でブロックされます。
- **長期休暇スキップ**: GWや夏季休暇の週は理由を記録して `SKIPPED` に移行可能。
- **管理者共有メモ**: 本人には非公開の管理職・営業間引き継ぎメモを別枠で永続化。
- **実装クラス**: `domain.weeklyreport.WeeklyReport`
